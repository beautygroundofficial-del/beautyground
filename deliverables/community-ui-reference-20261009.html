커뮤니티 UI 참고 기준

2026-10-09 · 소비자 홈과 이야기 목록

자료와 적용

  • 모임 앱 개선: 첫 화면의 목적, 정보 위계와 메뉴 의미를 명확히 한다. 짧은 안내 → 최신 대표 이야기 → 주제 탐색 순서로 구성한다.
  • 페르소나: 둘러보기·관심 주제 찾기·내 이야기 남기기를 설계 가설로 삼는다. 실제 사용자 조사로 확인한 유형은 아니다.
  • 해상도 기준: 과거 점유율 수치를 현재 기준으로 사용하지 않는다. 390px를 설계 기준으로 하고 360·430px와 PC 모바일 프레임에서 검증한다.

화면 규칙

  • 홈은 본문과 사진·영상 미리보기 중심 카드형.
  • 이야기 목록은 왼쪽 64px 썸네일, 오른쪽 본문 2줄.
  • 카테고리 → 본문·미디어 → 작성자·공감·댓글 순서. 선택 상태는 체크와 테두리로 표시.
  • 기존 브랜드 색상, 8px 카드 모서리, 영상 자동재생 금지를 유지.
  • 인기 카테고리 순위는 실제 이용 데이터 없이 지정하지 않는다.

후속 사용자 확인: 관심 주제 찾기, 영상 열기, 글 남기기. 글자 확대와 키보드 사용은 실제 기기에서 추가 확인한다.
