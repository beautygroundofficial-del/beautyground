# 커뮤니티 UI 재수정

2026-09-27. 대표님이 1차 UI 정돈에 대해 “뭐가 달라졌는지 전혀 모르겠다, 띄어쓰기만 바꾼 거냐”고 피드백했다. 1차 변경은 글자·여백 위주여서 차이가 약했다. 이번에는 기본 색상과 메뉴를 유지하면서 실제 앱의 정보 배치를 바꿨다. 대표님의 최종 디자인 승인을 받은 상태는 아니다.

## 변경

- 홈·이야기: 반복되는 둥근 외곽 박스를 없애고 글 사이 구분선을 사용한다. 작성자 첫 글자 표시·이름·시간을 본문 위로 옮겼으며, 이야기의 친구 버튼도 작성자 옆에 둔다. 사진은 작성자 아래에 놓고 사진 자체에만 둥근 모서리를 적용한다. 이름 가림 규칙은 동일하다.
- 댓글: 본문과 구분되는 옅은 배경, 댓글 수 제목, 작성자 위·내용 아래 배치. 답글의 들여쓰기와 댓글 작성란을 유지한다. 말풍선에 ‘댓글’ 글자를 표시한다.
- 쓰기 입구: 옅은 바탕과 남색 연필 표시로 읽는 글과 구분한다.
- 소식·친구: 카드 테두리 대신 목록 구분선과 종류별 아이콘·회원 이름 첫 글자를 사용한다. 받은 친구 신청은 옅은 배경과 수락·거절 버튼으로 구분한다.

변경 파일은 CommentThread, DiaryComments, DiaryHomeFeed, HomeBody, AppDiary, AppNews, AppFriends 7개다. 서버·DB·수수료·포인트 규칙 변경은 없다. 다른 세션의 로그인·관리자 변경은 포함하지 않는다.

## 확인과 한계

- 실제 앱 빌드 통과. 운영 기준 별도 작업트리에도 이번 7개 UI 파일만 반영해 최종 빌드가 통과했다.
- 격리된 SQL 및 두 브라우저로 기존 기능 검사 16/16 통과. 댓글·답글·친구 신청/수락/취소·소식 이동·초안 복원·실패 재시도 등을 확인했으며 JavaScript 오류와 예기치 않은 fixture 요청 실패는 0건이다.
- 홈/이야기/소식/친구/소식 빈 상태/친구 빈 상태를 320·390·480·1440px로 촬영했다. 수정본 24개에서 가로 넘침·검사 대상 텍스트 넘침·페이지 오류 0건이다. 키보드 포커스 48개 표본에 표시 누락·화면 밖 포커스 0건이다. 전체 접근성 인증은 아니다.
- 이전 비교의 after 이미지를 그대로 복사해 이번 before로 삼았다. 기존 증거를 다시 촬영하거나 덮어쓰지 않았다. 같은 한국어 예시 데이터와 외부 글꼴을 차단한 같은 로컬 대체 글꼴을 사용했다. 실제 회원 성과·실기기 검증은 아니다.
- 홈·이야기·댓글·소식·친구 캡처를 직접 확인했다. 운영 배포 및 기존 SQL 2건 적용은 여전히 승인 대기다.
