40·50·60대 회원이 부담 없이 글을 읽고, 쓰고, 서로 대화하는 흐름을 우선한다. 기존 흰 바탕·남색·목록 구분선·모바일 480px 구조를 유지한다. 이전 HTML 시안의 새로운 색상·통합 카테고리·글별 익명·팔로우 기능은 운영 승인 기능으로 취급하지 않는다. 수수료·판매·포인트 정책, 운영 콘텐츠·계정·DB 정책은 이번 범위에 넣지 않았다.

검토 근거는 원본 9/20 마인드맵과 볼트의 9/24 정정, 9/27 기획·클릭 시안, 커뮤니티 전환·개발 로드맵·카테고리 문서, 4050~60대 관심사·UX 자료, 친환경·걷기 방향, 9/21 첫 참여자 운영안, 9/27 제3자 분석, 9/28 운영 배포 기록이다. 실제 앱의 홈·이야기도 읽기 전용으로 확인했다. 과거 연구의 외부 통계와 원문을 새로 검증한 작업은 아니다.

현재 운영 기준은 `origin/main`의 `1ca155e`다. 이번 수정은 해당 커밋의 별도 사본에 대상 파일만 반영하여 빌드·검증했다. 작업 폴더에 남아 있는 다른 세션의 로그인·관리자·Supabase 변경은 후보에 포함하지 않았다.

| 글쓰기 | 입력 16px, 게시·첨부 주요 버튼 44px 이상. 공개 범위를 입력 전에 안내하고 본문 아래에도 게시 버튼을 제공한다. 첨부·이모지와 산책·펫·카드는 선택해서 펼친다. 속 이야기의 기존 주제는 한 줄로 접고, 미선택 게시 시 펼쳐 해당 위치로 안내한다. 주제 종류와 필수 조건은 유지한다. |

## 작업과 독립 검토

담당자가 구현하고 별도 검토자가 실제 코드와 재현 결과를 검토했다. 검토에서 발견한 초기 인증 조회 경합을 다시 수정했다. 기존 CLI 반복 실행기를 가동하거나 ChatGPT 웹 대화창에 자동 전달한 작업은 아니다.

수정 전 별도 빌드에서 두 계정의 공용 초안 노출과 홈 오류의 빈 목록 오표시를 재현했다. 수정 전 캡처와 결과를 보존하여 수정 후 결과와 비교한다.
