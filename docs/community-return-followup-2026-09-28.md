## 회원 수 조회 — 운영 DB 승인 대기

읽기 전용 운영 함수 목록 조회에서 `get_member_count()`가 없음을 확인했다. 기존 SQL은 7,321명 기준값에 2026-09-13 00:00 KST 이후 가입 수를 더하는 **표시용 값**이다. 실제 총회원 수·활성 회원 지표로 해석하면 안 된다.

`supabase/member_count.sql`에 빈 search_path, PUBLIC 실행권한 회수, anon/authenticated 실행권한, PostgREST 캐시 갱신을 명시했다. 격리 SQL 검사 8/8과 독립 검토 통과. 회원·글·댓글 데이터 변경은 없다. **운영 DB 실행은 별도 승인을 요청했으며 아직 실행하지 않았다.** SQL 파일이 Git에 저장되거나 웹이 배포되어도 운영 함수가 자동 생성되는 구조가 아니다.

승인 후에는 함수 부재를 다시 확인하고 기존 정의·권한을 백업한 뒤 적용한다. 실제 RPC 응답·권한·배포 결과를 별도 기록한다. 승인 전에는 앱 수정만 배포한다.
