# 커뮤니티 화면 디자인 정돈

2026-09-27. 대표님 요청에 따라 기존 화면 구조·흰 바탕·남색 글씨·둥근 카드를 유지하고 실제 앱의 표시 스타일을 정리했다. 이전 커뮤니티 기능 수정 `f90160f` 위에 적용한 UI 변경이며 운영 반영은 하지 않았다.

## 달라진 부분

- 홈과 이야기: 제목·본문·보조 정보의 크기와 여백을 구분했다. 카드 내부 여백을 20px로 맞추고 긴 글이 줄바꿈되도록 했다. 좁은 화면에서 제목과 정렬 버튼이 몰리지 않도록 정렬 버튼을 제목 아래에 배치했다.
- 댓글: 본문이 가로 폭을 충분히 사용하고, 작성자·답글·삭제는 아래 줄에 정렬한다. 답글 들여쓰기와 구분선을 정돈하고 입력칸은 전체 폭으로 둔다.
- 소식·친구·프로필: 목록 간격, 보조 설명 대비, 긴 이름과 문장 줄바꿈을 정리했다. 소식의 읽음 상태는 옅은 배경으로 구분하고 기존 카드 형태를 유지했다.
- 버튼: 주요 동작은 44px 이상 터치 높이를 확보했다. 기존 `button { border: none }` 때문에 빠지던 버튼 경계는 해당 커뮤니티 버튼에만 `border-solid`를 명시했다. 전역 CSS나 디자인 토큰은 바꾸지 않았다.

라우트·서버 요청·DB 함수·포인트·판매 정책은 이 UI 작업에서 바꾸지 않았다. 문구와 카테고리 개수도 유지했다. 홈의 작성 버튼과 이야기 작성 버튼에는 기존 아이콘 라이브러리의 연필 표시를 사용했다.

## 확인

- 기능 브랜치 정식 빌드 통과.
- 빌드된 앱과 격리 SQL을 연결한 두 별도 브라우저의 기존 사용자 흐름 **16/16 통과**. 댓글·답글·친구·소식·초안·실패 복구 검증이며 운영 계정 로그인 검증이 아니다.
- 디자인 비교는 수정 전후에 같은 한국어 예시 글을 사용한다. 비교용 인원수·이름·글·소식은 모두 fixture이며 실제 회원 성과나 운영 데이터가 아니다.
- 운영 기준 독립 사본(`c73797b` + 이전 커뮤니티 수정 `3dee625`)에 이번 UI 파일 14개만 반영한 **최종 정식 빌드 통과**. 다른 세션의 로그인·관리자 화면 변경은 제외했다.
- 홈·이야기·소식·친구 및 소식/친구 빈 상태, 총 6장면을 수정 전후 각각 320·390·480·1440px로 촬영했다. **수정 후 24개 화면에서 페이지 가로 넘침과 검사 대상 긴 텍스트 넘침 0건**. 전체 접근성 인증이나 실기기 시험을 의미하지 않는다.
- 수정 후 홈·이야기·소식·친구·댓글 이미지를 직접 확인했다. 주요 테두리 버튼의 계산 스타일은 `solid 1px`로 확인했다.

비교 파일: 다운로드 폴더의 `뷰티그라운드 커뮤니티 UI 정돈 (2026-09-27)/gallery.html`. 실제 앱 화면을 같은 한국어 예시 데이터로 촬영한 전후 비교다. 기존 HTML 기획 시안 파일은 그대로 두었다.

이전 기능 수정의 SQL·운영 적용 조건은 [커뮤니티 통합 검토 기록](community-integration-review-2026-09-27.md)에 있다. 이번 UI 정돈은 그 승인 대기 상태를 바꾸지 않는다.
